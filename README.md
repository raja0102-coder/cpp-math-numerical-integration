# Sem 2 Engineering Mathematics: C++ Numerical Integration Engine

A C++ numerical methods application implementing the Trapezoidal Rule and Simpson's 1/3 Rule for numerical integration in Semester 2 Engineering Mathematics.

## Mathematical Concepts Covered
* **Numerical Integration**: Approximating definite integrals when exact analytical integration is complex.
* **Trapezoidal Rule**: Approximating the region under the curve as trapezoids.
* **Simpson's 1/3 Rule**: Fitting quadratic parabolic arcs through data points for higher precision.

## How to Compile & Run
```bash
g++ main.cpp -o numerical_integration
./numerical_integration
